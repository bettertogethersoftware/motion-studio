    tts vendors

    who narrates — for the Studio and every connected agent

    The choice is global — agents connected over MCP use the vendor picked here too, unless a call names one explicitly. Tick more than one to make a preference chain: the highest-ranked vendor that is actually set up gets used, so a missing key falls through instead of failing. Reorder with ▲▼. A vendor that is set up but then fails is still an error — nothing is silently finished by someone else. API keys are read from the machine's environment only and are never written to settings.json.

    probing…

    The local MotionStudioTts.exe driving the OS voices. Offline, free, no account — Windows only, and limited to the voices installed on this machine.

    probing…

    Microsoft's cloud neural voices over REST — cross-platform, several hundred voices across ~140 locales, with expressive styles. Billed per character by your Azure subscription.

    Set the key on Windows with setx AZURE_SPEECH_KEY "<key>" (and AZURE_SPEECH_REGION), then restart the Studio — a new value only reaches an already-running process on restart. A region set in the environment overrides the field above.

    probing…

    Neural voices running entirely on this machine — no account, no per-character billing, no network, any OS. Installed separately (pip install piper-tts, GPLv3) with voices you download; each voice carries its own licence.

    Voices are two files each — en_US-lessac-medium.onnx and its .onnx.json — from huggingface.co/rhasspy/piper-voices. Drop both in the voices folder; everything there shows up in the picker.

    Renders a General MIDI SoundFont in-process (spessasynth_core) — no binaries to build, works on any OS, about 45× realtime. Same SoundFont, same spec, same sound as the external chain.

    probing…

    The v0.8 chain: MotionStudioMidi.exe authors the MIDI, fluidsynth.exe renders it. Windows-only, ~74 MB of binaries you build or download yourself.

    Target peak applies to both music vendors and only ever attenuates — a quiet arrangement stays quiet. It is what keeps a bed at the same loudness against your narration when you switch vendors.
