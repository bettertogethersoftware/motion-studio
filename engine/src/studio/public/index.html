    tts vendors

    who narrates — for the Studio and every connected agent

    The choice is global — agents connected over MCP use the vendor picked here too, unless a call names one explicitly. Tick more than one to make a preference chain: the highest-ranked vendor that is actually set up gets used, so a missing key falls through instead of failing. Reorder with ▲▼. A vendor that is set up but then fails is still an error — nothing is silently finished by someone else. API keys are read from the machine's environment only and are never written to settings.json.

    favorite voices

    Star a voice with the ☆ next to any vendor's voice picker. Starred voices save with the speech settings and are reported to connected agents (favoriteVoices in list_vendors), so narration prefers voices you actually chose. Click a chip to remove it.

    probing…

    The v0.8 chain: MotionStudioMidi.exe authors the MIDI, fluidsynth.exe renders it. Windows-only, ~74 MB of binaries you build or download yourself.

    Starred instruments save with the music settings and are reported to connected agents (favoritePrograms in list_vendors), so generated music leans on the sounds you actually like instead of defaulting to piano and strings.

    Target peak applies to both music vendors and only ever attenuates — a quiet arrangement stays quiet. It is what keeps a bed at the same loudness against your narration when you switch vendors.

    transcript

    startframesmin psentence

    start and frames are what an agent places a caption or a cut with — the same fields generated narration reports. min p is the least confident token in the sentence: a low number means the model guessed, so read it before putting those words on screen.

    Download a prebuilt whisper.cpp release (or build it), point executable at whisper-cli, and put a model such as ggml-small.en.bin from huggingface.co/ggerganov/whisper.cpp in a models folder beside it — that is the whole setup, and the folder is found automatically. Bigger models are more accurate and proportionally slower; .en models beat the multilingual model of the same size on English. Nothing here is a secret, so it all lives in settings.json.

    storage · where films, scenes and settings live on disk

    Leave a box empty for its default (shown greyed in the box). Relative paths are taken from the Motion Studio folder, so data keeps the install portable. Folders are created on save, and nothing is moved — point these at an existing tree, or copy your files across yourself first. The Studio switches over immediately; connected agents keep using the old location until their MCP server is restarted. A field the environment already sets (MOTION_STUDIO_HOME, _WORKSPACES, _SETTINGS) is shown locked — change it where that variable is set.
